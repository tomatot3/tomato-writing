# Tomato Writing · 通用研究论文写作技能

[English](README.md)

这套技能把长期改稿中形成的经验整理为可复用的判断方法，适用于不同研究对象和论文类型。重点是让读者理解问题、方法和证据，同时保护作者已确认的内容。

## 使用方式

将完整的 skills/research-writing-editor 文件夹复制到 Codex 的技能目录，通常为 ~/.codex/skills/research-writing-editor；使用自定义 CODEX_HOME 时，放入该目录下的 skills。若当前会话没有识别新技能，可开启新会话。

~~~text
使用 $research-writing-editor 修改这段引言。
先判断问题推导和文献之间的联系，再处理句式。
保留必要的方法解释和已确认文字，不以删字数量判断改进。
~~~

也可用于具体任务：

- 分析某段是否把本文任务当成研究缺口，先不改文件。
- 将方法中的实现笔记整理为连续说明，保留必要算法条件。
- 修改结果段的数字堆砌，保留有意义的统计量和不确定性。
- 按中文修正英文中的对象、时序与比较含义。
- 对照导师批注修改当前文件，并在原文位置展示改动。

默认允许自动调用。已有写作技能无需删除；按当前任务选用，不要机械叠加整套技能后反复改写同一段。

## 为什么采用一个入口和七份专题指南

主入口负责识别任务和选择判断层次。专题分别处理论证与文献、章节功能、证据表达、语句与术语、双语同步、文件修改保护和跨领域例子。局部修改只读取相关部分，全面修稿则可以按实际问题组合使用。

保留了以下容易在改稿中丢失的尺度：

- 不凭空制造gap，也不把必要的问题分析全部删掉。
- 避免文献流水账，同时保留读者理解方法所需的具体解释。
- 减少防御性表述，同时保留决定结论成立的条件。
- 统一术语，同时区分模型、实例、记录与显示结果。
- 数值有取舍，同时不隐去相关结果或机械删除置信区间。
- 修改清楚的研究表达，不强制短句、固定段数和禁词表。
- 尊重当前稿件和导师直改，区分准备副本与已写入正式稿。

具体内容从 [技能入口](skills/research-writing-editor/SKILL.md) 按需进入。材料均为通用规则与合成示例，没有收录私人稿件、作者信息或真实项目数据。

## 质量检查

运行 python scripts/validate_package.py 检查结构、链接与测试材料。行为测试见 [evaluation/README.md](evaluation/README.md)：观察技能是否真正保留机制、证据、作者意图和清楚句子，而不是只检查是否用了某个词。

采用 [MIT许可证](LICENSE)，允许复制、修改和分发，保留版权及许可声明即可。

技能也检查跨章节的语义重复：同一条件、机制或限制即使用不同措辞重述，仍可能增加阅读负担。判断每次出现是否承担新的作用，保留独立摘要、图注和必要比较条件，避免全文反复重新介绍同一件事。
