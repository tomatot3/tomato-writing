# Behavioural evaluation

The cases in cases.json are synthetic exercises. They test editorial decisions, not domain expertise or factual claims about real studies.

## Run a fresh-reader pass

Use an independent evaluator when the environment permits delegation. Provide the skill path and the selected case's task, facts, and draft. Withhold the checks field and any prior assessment. Ask for the actual revised prose and a brief note on guidance used. Give no access to a private manuscript, live publication destination, or mutable production files.

Some basic cases resemble the worked examples and serve as smoke tests. Additional transfer cases should vary the domain, evidence strength, quantities, and requested scope. Do not describe example reproduction as proof of generalization.

If delegation is unavailable, apply the same criteria to the actual output and report that the review was not independent. Do not invent a model run or report a self-filled pass flag as validation.

## Review observable decisions

- Does the output preserve supplied facts and the requested operation?
- Is the research issue established independently of the proposed technique?
- Are mechanisms explained rather than replaced with technique labels?
- Are necessary conditions retained without speculative caveats?
- Does the claim retain the strength justified by the evidence?
- Are numerical units, uncertainty, and aggregation unchanged?
- Does a clear original sentence remain when no repair is needed?
- Is the requested scope respected, including which language or file may change?

Do not score exact wording, sentence length, paragraph count, or presence of a preferred transition. A fluent answer that changes scientific meaning is a substantive failure. A different but faithful sentence is acceptable.

Record the actual outputs, substantive problems, and any resulting skill revision. Keep test outputs outside the installed skill so ordinary editing tasks do not load evaluation answers. Report the number and kinds of cases actually examined; do not turn a small exercise into a general claim of writing quality.
