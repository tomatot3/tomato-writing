# Revision integrity

Use for direct manuscript edits, advisor comments, revision comparisons, bilingual synchronization, and consistency across text, figures, SI, and deliverables. Apply checks proportionately to the change.

## Read the actual working document

Determine the current file and whether tracked changes should be read as accepted, rejected, or visible. Do not silently edit an older extraction or assistant-created draft when the user supplied a newer version. If a file cannot be opened, say what was actually inspected and continue only work supported by that material.

Distinguish advisor direct edits, comments suggesting a change, author approvals, and assistant recommendations. Preserve approved content. If a correction is necessary, identify the affected claim and change locally; do not use the existence of one error to authorize a broad rewrite.

Save a recoverable baseline before an extensive edit. Before writing back, check whether the user changed the source. If it changed, reconcile against the latest saved version; do not overwrite it with a prepared older copy. Do not close user applications or discard unsaved edits to obtain access.

## Keep changes reviewable

Choose the output that matches the request: clean copy, native tracked changes, comments, inline redline, or a brief change list. A list of paraphrases does not replace an in-place comparison when the author needs to inspect the exact wording.

For substantial work, record the changed passages and the reason each materially changed. Keep private internal reasoning, process logs, and detailed compliance tables out of the manuscript. Avoid exposing personal paths, authorship data, or unpublished material in public examples or skill repositories.

## Synchronize the affected objects

| Change | Check |
| --- | --- |
| New or removed reference | Bibliography order and citations in text, captions, tables, and relevant SI |
| Equation or section numbering | Main-text references and SI references back to the main text |
| Terminology | Definitions, later uses, figures, captions, and target-language counterpart |
| Data membership or experimental setting | Actual files, sample definitions, denominators, summaries, and resource statements |
| Figure edit or crop | The embedded object, independent submission figure, and visible caption |
| Prose expansion or compression | Pagination around figures, tables, equations, and headings |

Do not change an independently numbered supplementary item merely because a similarly numbered main-text item changed. Distinguish datasets with equal sample counts but different purposes.

Use the current venue's requirements when an actual formatting question depends on them. Do not assume all journals ban title punctuation, require the same abstract length, omit access dates, or place Methods identically. A style preference should be described as a preference.

## Separate textual and visual checks

Text extraction can confirm wording and references; it cannot establish whether a formula is clipped, a table is split badly, or panel letters differ in size. Inspect rendered affected pages with the available document/PDF workflow. Expand inspection if pagination changes propagate.

A render can reveal layout but does not establish source support or algorithm correctness. Preserve image and numerical evidence. Do not retouch scientific outputs to make a comparison look better. Keep design mockups distinct from raw experimental evidence and historical sources.

## Install and report accurately

A prepared revision, rendered PDF, copied final manuscript, and published repository are separate states. Check the actual requested destination before reporting completion. If writing back is blocked, preserve the prepared work and explain the specific remaining action.

Only edit or publish the scope authorized by the user. This writing skill does not decide authorship, invent author contributions, select a license, upload files, or send reviewer responses without appropriate instruction.

## Freeze without pretending perfection

After fixing the identified problem, reread the relevant section continuously. Keep clear passages unchanged. Do not reopen the entire paper because another wording is possible.

Fresh-reader review is useful for detecting assumptions the authors no longer notice. Give such a reader the manuscript and intended audience without coaching the desired conclusion. Treat their questions as evidence of possible reading difficulty, not automatic proof that every preference requires revision. A change in a simulated review label is not by itself a reason for another major rewrite.
